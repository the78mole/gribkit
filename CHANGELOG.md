# Changelog

Every commit on `main` produces a release. The release notes are generated from the commit
messages and published on the
[GitHub Releases page](https://github.com/the78mole/gribkit/releases).

The project follows [Semantic Versioning](https://semver.org/). Versions are derived from
[Conventional Commits](https://www.conventionalcommits.org/): `feat:` bumps the minor version, a
breaking change (`feat!:`, `fix(idx)!:`, ...) bumps the major version, and every other commit bumps
the patch version.

## History before 0.2.0

gribkit 0.1.0 was developed inside [PredictionDB](https://github.com/the78mole/PredictionDB) and
was never published on PyPI. 0.2.0 is the first public release.
